KC8GW complete site update — October 6, 2026

INSTALL
Upload the CONTENTS of KC8GW-main into the root of your existing website repository. Include the new repeater-road-map folder, roadmap.html, assets/js/sports.js, and assets/css/cleanup.css. Keep CNAME at the repository root. After uploading, use Ctrl+F5 to refresh the browser.

SPORTS
Sports now renders its own MLB / NFL / NHL / NBA / NASCAR / PGA scores and schedules from ESPN. It no longer embeds the Pi root address, which was displaying the road map. Feed errors have an ESPN link and a Refresh button. Current schedules refresh while the page is visible.

ROAD MAP / CSV IMPORT
The ROAD MAP tab opens roadmap.html; Open full-screen map opens repeater-road-map/index.html.
1. Press Upload CSV at the top of the map.
2. Select Site_info_20261005_224911.csv to load the 319 supplied repeaters with coordinates.
3. For mode and receive-tone details too, select BOTH this file and RB_2610052246.csv together in the file picker. Ctrl-click selects both files on Windows.
4. The importer combines matching entries. It distinguishes the separate W8EOC 147.030 entries in Medina and Brunswick.
5. Use My location and select bands / distance. All bands includes records outside the default 2m / 70cm selection.

CSV imports remain in your browser, across page reloads. They are not uploaded for other visitors. To update, upload the latest CSV (or pair of CSVs). Each import replaces the previous browser dataset. Both recognized CSV formats can be imported; rows lacking coordinates stay searchable in the list. Place town on map is an optional manual approximation for coordinate-free files. No automatic geocoding is needed for your coordinate file.

The uploaded repeater data files are not bundled into this public website; use your downloaded files with Upload CSV. Only an empty initial dataset ships with the tool.
