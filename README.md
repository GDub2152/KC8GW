# KC8GW.com

Static GitHub Pages website for KC8GW.

## Publish
1. Upload all files and folders to the root of the GitHub repository.
2. In Settings > Pages, deploy from the `main` branch and `/ (root)` folder.
3. Keep the included `CNAME` file containing `kc8gw.com`.
4. After DNS verifies, enable Enforce HTTPS.
