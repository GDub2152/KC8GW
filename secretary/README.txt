KC8GW Secretary Meeting Minutes Assistant
=========================================

PURPOSE
A self-contained browser-based meeting minutes assistant for The Blowtorch of Parma Amateur Radio Club.
Designed for iPad, Windows PC, Mac, or other modern browser.

FEATURES
- Structured meeting form matching the club's current minutes format
- Board/officer attendance list
- Call to order and quorum
- Previous-minutes motion and vote
- Treasurer and Secretary reports
- Old business, new business, announcements, presentation
- Adjournment motion and vote
- Live formatted minutes preview
- Print / Save as PDF using the browser
- Automatic local draft saving
- Export/Import JSON backup files
- No database, account, API, or external service required

INSTALL ON KC8GW.COM
1. Upload this entire folder as /secretary/ under the KC8GW.com web root.
2. The tool will then be available at:
   https://kc8gw.com/secretary/
3. Add a link on the main KC8GW.com page, for example:
   <a href="/secretary/">Secretary Meeting Minutes Assistant</a>

IMPORTANT ABOUT SAVING
Drafts are saved to the web browser on the device you are currently using.
An iPad draft will not automatically appear on a PC.
Use Export Backup on one device and Import Backup on another if you want to move a meeting between devices.
A future version can add cloud synchronization/login if desired.

PRINTING / PDF
Use the "Print / Save PDF" button. On Windows, choose "Save as PDF" or your printer.
On iPad, use the standard iOS print/share workflow to create or save a PDF.
