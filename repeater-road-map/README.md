# KC8GW Repeater Road Map

Upload CSV at the top selects one or multiple files. RepeaterBook radio-programming exports and coordinate site-info exports are supported. Select both exports to combine radio details and coordinates. Data is saved only in the importing browser. An import replaces the current browser dataset.

For an existing Pi installation, copy the contents of this folder into its existing repeater-road-map directory. The service worker is versioned and refreshes the application shell. This tool has no server component.

Optional fields: output frequency, input frequency, offset, uplink / downlink tones, callsign, city / location, county, state, modes, digital access, latitude, longitude. Frequency and callsign should identify the repeater. Without coordinates, a record is listed but not mapped until manually placed. Manual placements are marked approximate.

Range and coverage circles are estimates. Confirm repeater details before transmitting. Map tiles: OpenStreetMap. Repeater data: supplied by the user; attribution link to RepeaterBook is shown.
